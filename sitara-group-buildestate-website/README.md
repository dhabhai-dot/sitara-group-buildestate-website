# Sitara Group Buildestate Website

Production-ready static website for Sitara Group Buildestate.

## Deployment

This project is ready for Vercel as a static website.

- Framework preset: Other
- Build command: `npm run build`
- Output directory: project root
- Entry file: `index.html`

## Files To Upload

Upload the project files from this folder, including `assets/`, `index.html`, `styles.css`, `script.js`, `package.json`, `vercel.json`, `robots.txt`, `sitemap.xml`, `.gitignore`, and `.vercelignore`.

Do not upload the local helper folder `github-upload/`. It is already ignored in `.gitignore` and `.vercelignore`.

## Website Files

- `index.html` - complete website markup, sections, SEO metadata and map embed
- `styles.css` - responsive luxury real estate UI, logo area, gallery, mobile menu and animation styling
- `script.js` - mobile menu, animations, counters, team rendering, gallery lightbox and enquiry form handling
- `package.json` - Vercel build script
- `vercel.json` - Vercel routing and production headers
- `robots.txt` and `sitemap.xml` - SEO support files
